# Refactorización SOLID Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Corregir los errores reproducidos y separar responsabilidades conservando las 192 orientaciones.

**Architecture:** Catálogo JSON fuente, constructor puro, repositorio y validadores independientes. Servicio de orientación con dependencias sustituibles; Flask y Streamlit presentan resultados.

**Tech Stack:** Python 3.10+, unittest, Flask, Streamlit, Ollama opcional.

**Spec:** docs/propuesta_solid.md (aprobada).

## Global Constraints
- Mantener Python, Flask, Streamlit, rutas públicas y nombres compatibles.
- No introducir base de datos ni cambiar la experiencia visual.
- Conservar las 192 orientaciones y el TXT como documento histórico fuera de modelo.

## Review Focus
- JSON nulo, escalar, malformado o con claves duplicadas: rechazo explícito.
- Booleanos y números no finitos: no convertirlos silenciosamente.
- Árbol truncado, listas de campos incorrectas y hermanos duplicados: rechazo antes de usarlo.
- Caída o respuesta inválida de Ollama: respaldo sin perder la ficha.
- Cambios de configuración y recarga en Streamlit: no mostrar una guía con configuración anterior.
